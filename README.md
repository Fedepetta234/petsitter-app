Descripción del proyecto
¿Qué es PetSitter?

PetSitter es una aplicación pensada para conectar dueños de mascotas con personas que ofrecen servicios de cuidado de animales. La plataforma permite encontrar cuidadores de manera rápida y segura.

¿Qué problema intenta resolver?

Muchas personas necesitan alguien de confianza para cuidar a sus mascotas cuando trabajan, viajan o no pueden atenderlas. PetSitter busca facilitar la búsqueda de cuidadores y mejorar la comunicación entre ambas partes.

¿Quiénes son los usuarios principales?
Dueños de mascotas que necesitan ayuda con el cuidado de sus animales.
Cuidadores de mascotas que quieren ofrecer sus servicios.
Funcionalidades actuales
Landing principal informativa.
Registro e inicio de sesión de usuarios.
Visualización de cuidadores disponibles.
Perfil de usuarios y cuidadores.
Sistema básico de contacto entre usuarios.
